# EMPIRIAN App Project

An Ionic + Capacitor application for transacting via P2P communication using SignalR.

EMPIRIAN is a demo project for me to learn and experiment with SignalR and P2P communciation.

## Modules

In the `modules` dir, the `chat` module is a simpler testing ground where I first experimented with SignalR functionality before integrating it into the main app.
The `wallet` module is the primary, active module for the app. Showcasing P2P transactions via SignalR.
